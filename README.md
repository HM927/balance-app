# 残高管理アプリ

基準日時点の残高と、その後の収入・支出を登録し、指定日時点の残高を確認できるアプリです。

## 実装済み機能

- 基準残高・基準日の保存と表示
- 収入・支出の登録（日付、金額、メモ）
- 登録した収支の削除
- 収支を日付順に並べた一覧表示
- 基準残高と収支をもとにした指定日時点の残高計算

## 使用技術

- HTML
- CSS
- JavaScript
- localStorage

基準残高・基準日と収支データは、`localStorage`を利用してブラウザ上に保存しています。そのため、バックエンドやデータベースは使用していません。

## 今後の改善案

バックエンドAPIやデータベースを導入し、ブラウザ内に限らないデータ管理へ拡張する予定です。
